# U 盘随身盘标准档

本文回答三个问题：

1. 什么样的盘算好，什么样的盘算差？
2. 好到什么程度可以拿来做随身 Linux？
3. 历史评测结果在哪里看？

历史记录见 [evaluations/README.md](../evaluations/README.md)。

---

## 1. 先看什么指标

| 指标 | 为什么重要 |
|---|---|
| **顺序写** | 安装系统、复制大文件、更新包 |
| **4K 随机写 QD1** | 浏览器缓存、日志、小文件、桌面响应 |
| **4K 写 + fsync** | `dpkg`/`apt` 每写一个文件后的持久化，最接近真实安装体验 |
| **顺序读** | 启动、加载应用；高读不能弥补低写 |
| **4K 随机读** | 启动、程序加载、索引 |
| **协议 UAS/BOT** | UAS 通常随机性能更好；BOT 在廉价盘上很常见 |
| **写缓存** | `write back` 通常快于 `write through` |

**读速度不是决定性因素。** 一支盘可以读 200MB/s、写 1.5MB/s，装系统时仍然不可用。

---

## 2. 随身盘等级（Tier）

先按顺序写 + 4K 随机写定级，再用 fsync 做降级修正。

| 等级 | 顺序写 | 4K 随机写 QD1 | fsync 4K | 用途 |
|---|---:|---:|---:|---|
| **S 优秀** | ≥ 150 MB/s | ≥ 20 MB/s | ≥ 1.0 MB/s | 主力便携开发盘，长期使用 |
| **A 推荐** | ≥ 60 MB/s | ≥ 8 MB/s | ≥ 0.7 MB/s | 日常随身，apt/IDE 可接受 |
| **B 轻量** | ≥ 25 MB/s | ≥ 3 MB/s | ≥ 0.5（低于 0.5 仍可为 B，但只轻量/应急） | 轻量随身/应急；避免大批 apt、Docker |
| **C 勉强** | ≥ 10 MB/s | ≥ 1 MB/s | ≥ 0.3（低于 0.3 仅应急） | 只做 live/维护/数据盘，不建议完整安装 |
| **D 不合格** | < 10 MB/s 或 < 1 MB/s | - | - | 不建议做启动盘 |

> 工具的 `GOOD/PASS/WARN/FAIL` 是粗筛；本表 `S/A/B/C/D` 是使用等级。二者不一致时以 Tier 为准，尤其是 fsync 临界的情况（例如 LanKxin 工具 GOOD，但 fsync 0.49 → B）。

### fsync 降级规则

- fsync < 0.7 MB/s：S 降为 A
- fsync < 0.5 MB/s：S/A 降为 B
- fsync < 0.3 MB/s：最高只能到 C

> 例：LanKxin 顺序写 98MB/s、4K 22.8MB/s，按主指标是 A；但 fsync 0.49MB/s，降为 **B**。

### 结论：什么程度可以做随身盘

| 目标 | 最低等级 | 说明 |
|---|---|---|
| 日常随身 / 便携开发 | **A** | 推荐；apt、IDE、浏览器都比较从容 |
| 轻量随身 / 应急 | **B** | 能用；避免大型 `apt upgrade`、Docker、重度缓存 |
| 只做 live/维护/数据盘 | **C** | 不建议装完整系统 |
| 不建议使用 | **D** | 换盘，别浪费时间 |

**一句话：A 及以上可以当日常随身盘；B 只能轻量用；C 只应急；D 不要用。**

## 3. 好盘 / 差盘的特征

### 好盘

- **UAS** 协议、**write back** 写缓存
- 顺序写 ≥ 60MB/s（A 线），4K 随机写 ≥ 8MB/s
- fsync ≥ 0.7MB/s
- 顺序读 ≥ 100MB/s，4K 随机读高
- 持续写入几 GB 后不明显掉速（SLC 缓存/温度控制好）
- 真实容量、稳定主控、足够剩余空间（建议 ≥ 20%）
- 在 USB 3.x 蓝色接口上测试

### 差盘

- **BOT + write through**，`hdparm -W1` 打不开写缓存
- 顺序写 < 10MB/s 或 4K 随机写 < 1MB/s
- fsync < 0.3MB/s
- 读 200MB/s、写 1.5MB/s 的“读快写慢”盘
- 廉价无缓存主控、扩容/假容量盘
- 写几 GB 后掉到个位数 MB/s（SLC 缓存耗尽）
- 插在 USB 2.0 口/劣质 Hub 上

### 灰色地带

- B/C 级盘：能启动，但升级、缓存、Docker 会慢；只适合轻量/应急。
- 品牌不是保证：同一品牌不同批次可能完全不同，**每批都测**。
- 4K 写入很高但 fsync 很低：apt 仍然慢，按 fsync 降级。

---

## 4. 测试条件

- 优先用 **full 模式**（256MB 顺序 + 10s 随机）做最终判断；quick 只做批量初筛。
- 文件系统影响结果：
  - ext4/xfs/btrfs 最接近装系统；
  - exFAT 不支持 O_DIRECT 时会走缓冲，4K 写可能被页缓存抬高；
  - NTFS/FUSE 有额外开销。
- btrfs 有 CoW 开销；结果可能略低于 ext4。
- 新盘第一次写入可能很快，缓存耗尽后掉速；建议写入几 GB 后复测。
- 测试会写约 200MB（quick）/600MB（full），不要反复测同一支盘。
